# Learn English

Ứng dụng web học tiếng Anh cơ bản, xây dựng bằng HTML, CSS và JavaScript.

## Chức năng
- Hiển thị danh sách từ vựng tiếng Anh cơ bản.
- Đánh dấu từ đã học.
- Kiểm tra kiến thức bằng 10 câu hỏi trắc nghiệm.
- Theo dõi số từ đã học, số lượt kiểm tra và điểm cao nhất.
- Lưu tiến độ bằng Local Storage trên trình duyệt.

## Chạy ứng dụng
Mở tệp `index.html` bằng trình duyệt Chrome, Edge hoặc Firefox.

## Triển khai GitHub Pages
1. Tạo repository tên `learn-english` trên GitHub.
2. Đưa toàn bộ tệp trong thư mục dự án lên repository.
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn nhánh `main`, thư mục `/(root)`, sau đó nhấn **Save**.
6. Truy cập địa chỉ GitHub Pages được GitHub cung cấp.

## Lưu ý
Đây là ứng dụng web tĩnh phục vụ bài thực hành. Dữ liệu học tập được lưu trên trình duyệt của từng thiết bị; chưa có tài khoản người dùng hoặc cơ sở dữ liệu dùng chung.
